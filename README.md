# İyi Ki Aileyiz — Animasyon Projesi

6–9 yaş çocukları için güvenli aile iletişimini olumlu davranış modelleriyle anlatan 15 bölümlük animasyon kamu spotu serisinin iki dilli proje sunum sitesidir.

## Site kapsamı

- Türkçe / İngilizce dil geçişi
- Masaüstünde tam navigasyon, mobilde hamburger menü
- Projenin sosyal gerekçesi ve pedagojik yaklaşımı
- Yalın Ailesi karakter evreni
- 15 bölümün değer, sinopsis, dört sahnelik animatik omurga, kazanım ve sohbet kartları
- Üç kilit bölüm için etkileşimli karakalem storyboard/animatik ön izlemesi
- Üretim, kalite güvence, erişilebilirlik ve etki ölçüm sistemi

## Yerel çalışma

```bash
npm run install:ci
npm run dev
```

## Üretim derlemesi

```bash
npm run build
```

Statik çıktı `dist/client` dizininde oluşur. `.github/workflows/deploy.yml`, `iyi-ki-aileyiz` adlı GitHub deposunda GitHub Pages yayınına hazırdır.
